#  LIMA - Linguagem de Marcação

Repositório dedicado ao armazenamento de atividades, projetos e conteúdos práticos da disciplina de **LIMA** (Linguagens de Marcação e Estruturação de Conteúdo).

---

##  Tecnologias Estudadas

Neste repositório, exploramos o desenvolvimento web fundamental através de:

- ![HTML](https://img.shields.io/badge/html5-%23E34F26.svg?style=for-the-badge&logo=html5&logoColor=white) **HTML5**: Estruturação de páginas web e elementos semânticos.
- ![CSS](https://img.shields.io/badge/css3-%231572B6.svg?style=for-the-badge&logo=css3&logoColor=white) **CSS3**: Estilização, layout, cores e responsividade.
- ![JavaScript](https://img.shields.io/badge/javascript-%23F7DF1E.svg?style=for-the-badge&logo=javascript&logoColor=black) **JavaScript**: Interatividade e dinamismo para as páginas.
